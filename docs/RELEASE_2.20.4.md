# 2.20.4 · 成果预览与局部修改

在回答的「本轮文件与产物」中展开文件，点击「查看预览」。

- PDF：在应用内查看页面，支持前后翻页。
- Word（DOCX）：查看正文、标题、图片和表格；这是内容预览，准确分页与排版仍使用默认程序。
- Excel（XLSX/XLSM）：切换工作表、查看已保存的单元格值；只读，每张表最多显示前 200 行、50 列，不执行宏、不重新计算公式。
- Markdown / TXT：预览、直接编辑、选中文字后替换，点击「保存文件」才修改磁盘。保留 UTF-8 和原有未改动部分的换行格式。
- 已保存文字的选区可以「带入对话修改」；保留已有输入草稿，补充要求后由用户发送。
- 保存前检查文件是否已被其他任务修改；有冲突时保留草稿，重新读取磁盘内容后可手动合并。
- 「历史版本」保留最近 20 个不同内容版本（含当前文件）。恢复前的内容也会保留，可再次恢复。记录存于本机应用数据目录的 `artifact-versions` 中，不自动同步到云端。
- 关闭或切换预览会保留未保存的编辑草稿，直到退出应用。任务运行时可编辑草稿，结束后保存。

文档预览上限 25 MB；编辑仅支持 1 MB 以内的 UTF-8 Markdown / TXT。DOCX、表格和 PDF 本轮提供预览，尚不支持直接编辑。沿用 2.20.3 的输入法保护、模式切换语义、流式阅读稳定和关闭窗口后后台继续。

验证覆盖真实 Electron 界面的预览、键盘选区替换、保存、关闭后草稿恢复、外部修改冲突、历史恢复、对话草稿追加，以及文件层的持久化恢复、大小与编码限制、Windows 换行保护。使用隔离资料和测试文件，没有修改真实账号数据。
