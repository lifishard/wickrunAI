## 安装程序同意页

4.1.1 起，Windows 安装程序在安装前显示许可页，用户点「我接受」才能继续。页面内容是根目录的 LICENSE（已定稿，不含占位），由 `npm run licenses` 生成为 `build/license.txt`（UTF-8 带 BOM、CRLF 换行，否则 NSIS 会把中文显示成乱码）。自动更新以静默模式运行，不会再弹这一页。

公司全称确定、EULA 定稿后：

1. 用定稿的 EULA（中英文）替换 LICENSE 正文，把权利人改为公司全称，运行 `npm run licenses` 重新生成安装程序许可页和第三方清单。
2. 首次登录云账号时，在应用内展示用户协议和隐私政策的链接，并记录同意的版本和时间；网站上增加 `/terms`、`/privacy` 两个页面放定稿。
3. 版本说明写明许可变更。

macOS 的 DMG 和 Linux 包暂不加同意页：DMG 许可需要 `build/license_<语言>.txt` 并在 macOS 上打包，等 macOS 签名一起做。

## 起草时发现的代码与文档问题

隐私政策按代码的实际行为写成，下列几处建议在正式发布政策前处理：

- **没有删除账号和导出全部数据的接口。** 政策暂时写成“发邮件由我们处理”。PIPEDA 和 BC PIPA 要求能在 30 天内响应查阅和删除请求。
- **云同步会上传 API 密钥**，服务器用自己持有的密钥加密，可以解密，不是端到端加密。桌面版 README 的 2.9 文件夹同步一节说“API 密钥不参与同步”，这只适用于文件夹同步。建议在开启同步的界面上明确说明，并允许只同步对话、不同步密钥。
- **桌面端本机保留模型请求与响应副本**（`runtime-v2/exchanges`），没有清理机制，会持续占用空间。
- **系统密钥库不可用时，密钥以明文保存**在本机，界面上应当提示。
- **连接器与中继任务**（目标、结果、图片）在服务器上没有自动过期。
- 网页版 `src/lib/transport.ts` 的注释说模型转发“仅用于开发”，实际生产环境在用；README 的免责声明原写“不代理任何访问”，已在 4.1.1 改为如实描述。
- `SECURITY.md` 原写“没有自动更新”，实际默认每 4 小时检查一次；已在 4.1.1 更正。
