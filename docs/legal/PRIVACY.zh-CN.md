## 1. 简要说明

- **不登录账号时，桌面端不向我们发送任何内容。** 你的对话、文件和设置保存在你的设备上；对 AI 模型的请求由你的设备用你自己的密钥直接发给你配置的服务商。
- **登录账号并开启云同步后，** 我们保存你同步的内容——包括你保存的模型 API 密钥——让你的设备之间保持一致。
- **网页版** 会经我们的服务器把模型请求转发给你选择的服务商，不保存请求内容。
- **今日管家** 在你同意之前不收集任何内容，原始记录只在你的设备上保留不超过 24 小时，并且可以让它忘记。
- **我们没有统计分析、广告或追踪，** 不出售个人信息，也不用你的内容训练 AI 模型。

## 2. 保存在你设备上的信息

桌面端把你的对话、项目、设置和任务记录保存在你的电脑上（应用的用户数据文件夹）。模型 API 密钥通过操作系统的密钥库加密（Windows DPAPI、macOS 钥匙串、Linux libsecret）；没有可用的密钥库时，密钥会以未经该加密的形式保存在设备上。应用还会在本机保留近期模型请求与响应的副本（用于任务恢复和查看），以及记录窗口崩溃和内存占用的本地日志。除非你登录并同步，这些内容都不会发送给我们。

网页版把你的数据保存在浏览器存储中；API 密钥保存在浏览器会话存储里，浏览器会话结束即清除（你选择同步的除外）。

## 3. 我们收集的信息

### 3.1 账号

你使用 Google 账号登录。我们会接收并保存你的 Google 账号标识、已验证的电子邮箱和显示名称，不会接收你的 Google 密码。为让你保持登录，我们保留登录会话：网页端为有效期 7 天的 Cookie；其他设备为令牌，我们只保存其哈希值。

### 3.2 云同步

开启云同步后，我们保存你同步的类别：对话、项目、技能、定时任务、观察记录、模型连接配置（每个服务商的名称和地址）、任务记录、今日管家的结果（见 3.6）和偏好设置。我们还会保存你已保存的**模型 API 密钥**，以便你的其他设备使用。密钥在存储时使用 AES-256-GCM 加密，加密密钥由我们的服务器持有：这能在存储被泄露时保护密钥，但不是端到端加密，我们的系统可以解密密钥，以便把它返回给你的设备。

如果你开启**端到端加密**，同步记录和文件会在你的设备上加密，所用密钥只保存在你的设备上，另有一把只有你保管的恢复密钥。我们无法读取这些内容；如果你同时丢失设备和恢复密钥，我们也无法帮你恢复。API 密钥不在端到端加密范围内。

### 3.3 文件

附件和项目文档可以通过临时中转在你的设备之间传输（单个文件最大 110 MB，约 7 天后删除）。你在云端生成或保存的媒体文件，以及你共享的文件，会在你方案的额度内保存在云端对象存储中。

### 3.4 共享与协作

你共享某项内容后，我们会保存该内容及其访问设置，并按角色向被共享的人展示：内容本身、带作者名字的评论、包含早期版本和每位编辑者名字的编辑历史、带发送者名字的聊天消息，以及带验收人名字、邮箱和时间的项目看板判定。空间管理员可以看到成员的电子邮箱。如果某个链接允许访客评论，我们会在访客的浏览器中设置有效期 30 天的 Cookie，并仅在内存中使用访客链接令牌和 IP 地址的哈希值来防止滥用。

### 3.5 网页版的模型请求

网页版调用 AI 模型时，浏览器会把请求和你的 API 密钥发送到我们的服务器，由服务器转发给你选择的服务商（仅限一份固定的受支持服务商列表），再把响应以流的方式传回。我们不记录、不保存这些请求或响应的内容。

### 3.6 今日管家

在你同意它所展示的数据范围之前，今日管家处于关闭状态。经你同意，并且只从你允许的来源和应用中，它可以读取：

- **浏览器页面**：通过应用生成的浏览器扩展，读取你允许的网站上页面的主要可见文字（最多 8000 个字符）。它会跳过无痕窗口、登录和付款页面，以及邮件和聊天网站。
- **桌面应用**：你允许的应用的前台窗口中的可见文字（在 Linux X11 上只读取窗口标题）。为方便你选择，它会列出正在运行的应用名称。

它不会截图，不会读取剪贴板或浏览器历史记录，也不会为此读取文件。原始记录只保存在你的设备上，用操作系统密钥库加密，最多保留 24 小时、500 条；密钥库不可用时，今日管家不会收集。默认情况下，它会把经过脱敏的摘录发送给你选择的 AI 模型，用来撰写简报和建议。如果你已登录，它推导出的结果——信号、目标、简报、建议与已接受的任务、审计记录、你的反馈以及“忘记”标记——会随你的账号同步。撤回某个来源的同意会删除该来源的原始记录；“忘记”会在你所有设备上删除相应内容。

### 3.7 手机遥控、云端中继与连接器

- **手机遥控**（默认关闭）让同一局域网内的手机凭令牌在你的电脑上运行工具，不经过我们的服务器。
- **云端中继**（默认关闭）让你的设备经我们的服务器互相交接任务；它会上报你的电脑名称以及本机可用的 AI 客户端。
- **连接器端点** 让你授权的 AI 客户端向你的工作区发送任务。以这种方式发送的任务目标、结果和图片会一直保存，直到你删除。

### 3.8 更新与下载

应用会向我们在 GitHub 上的公开发布仓库检查更新（启动约 20 秒后及之后每 4 小时一次，可关闭），下载页面也会在那里查询最新版本。GitHub 会依其隐私政策接收你的 IP 地址和该请求。

### 3.9 技术日志

我们不运行统计分析或崩溃上报。我们的托管和存储服务商可能会为运营和保护其网络记录标准技术日志，例如 IP 地址、时间和请求的地址。

### 3.10 付款

我们目前不处理付款。付费方案推出后，付款将由支付服务商处理；在收集任何付款信息之前，我们会更新本政策。

## 4. 我们如何使用信息

我们使用个人信息来：提供并保护你的账号和本服务；同步你的数据，并把它送达你的设备和你共享的对象；运行今日管家及你开启的其他功能；回复你；防止滥用；履行法律义务。我们不将其用于广告，不出售，也不用你的内容训练 AI 模型。

## 5. 我们与谁共享

- **服务提供商**，为我们托管和存储数据：[Railway——托管与数据库，地区：服务器所在地区]；[Cloudflare——R2 对象存储]；Google——登录。它们只能按我们的指示处理信息。
- **你连接的 AI 服务商及其他服务**，在你让应用或网页版向其发送请求时。
- **你共享的对象**，见 3.4。
- **政府机关**，在法律要求时，或为保护用户、公众或我们的权利、安全和财产所必需时。
- **承继方**，在我们的业务被合并或出售时，仍受本政策约束。

## 6. 信息存储地点

我们的服务器位于[服务器所在地区]，对象存储由 Cloudflare 提供，可能在多个国家存储数据。因此，你同步的信息可能在加拿大及你所在国家/地区以外存储和处理，并可能依当地法律被当地机关调取。

## 7. 保留期限

- 账号和同步数据：在账号有效期间保留；你删除内容或注销账号后 30 天内删除，备份中的副本在此后 [备份保留天数] 天内删除。
- 设备间中转的文件：约 7 天。未完成的上传：24 小时。不再被引用的媒体文件：48 小时。
- 共享内容：删除后对他人隐藏；其编辑历史保留至你的账号被删除。
- 登录会话：网页端 7 天；设备令牌 30 天后过期。90 天未活动的同步设备会被移除。
- 连接器与中继任务：保留至你删除它们或注销账号。

## 8. 安全

我们使用 HTTPS，对存储的 API 密钥加密，为同步提供端到端加密，只保存登录令牌的哈希值，限制网页版转发可访问的服务商，并限制对生产系统的访问。没有任何系统是绝对安全的；请为你的 Google 账号设置强密码并开启两步验证。

## 9. 你的权利与选择

在应用中，你可以删除对话、项目、文件和已保存的密钥，下载或清除今日管家记住的内容，让设备退出登录，并关闭同步、今日管家、云端中继和更新检查。你可以随时撤回同意；撤回后部分功能将无法使用。下载或删除整个账号的应用内入口正在规划中；在此之前，请写信至 admin@wickrunai.com，我们会为你处理。你也可以写信至该邮箱，要求查阅、更正或删除我们持有的你的个人信息，我们会在 30 天内答复。根据你所在地的法律，你可能还享有其他权利。如对我们的答复不满意，你可以联系不列颠哥伦比亚省信息与隐私专员办公室或加拿大隐私专员办公室。

## 10. 儿童

本服务不面向 13 岁以下的儿童，我们不会在知情的情况下收集其个人信息。如果你认为有儿童向我们提供了个人信息，请联系我们，我们会将其删除。
