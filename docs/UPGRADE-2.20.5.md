# 2.20.5：文档修改与媒体输入

## 文档预览和修改

- PDF 支持文字搜索、匹配页面跳转、缩放、选择复制；扫描件仍需 OCR。
- DOCX 可用本机 Word（Windows）或 LibreOffice 生成分页预览；没有排版程序时保留内容预览。
- Markdown / TXT 预览选区可提出 AI 修改要求，逐项接受或拒绝，应用到草稿后再保存。支持撤销本次 AI 草稿和历史恢复。当前建议生成使用配置的 API 模型。
- DOCX 可修改普通正文段落，XLSX / XLSM 可修改已有单元格。保留其他文件部分；复杂域、图形段落、公式和受保护工作表只读。新增文字继承修改处格式，复杂版式请用原应用核对。
- PDF 可旋转页面和增加可见文字批注，不支持替换原有正文。批注是覆盖显示，不是删除或脱敏。
- 二进制文档最多 25MB，保存前核对原文件版本，保留最近 10 个内容版本；Markdown / TXT 保留 20 个。未保存草稿只保留至退出应用。

## 图片、音频、视频

输入框“＋ → 添加图片、音频或视频”提供三种处理方式：原始媒体、先转文字、视频抽帧。转换文字可先检查修改，再加入对话；处理模型可与对话模型不同。

- API 原始音频使用 WAV / MP3 输入；其他浏览器可解码音频先转为单声道 WAV，转换上限 5 分钟。原始视频仅适用于服务支持的视频输入协议。单个媒体文件上限 12MB，服务可有更小限制。
- 能力优先取模型服务声明，亦可在对话设置登记；未知音视频能力需要用户确认。转换会使用所选服务的额度，不会无声丢弃不支持的媒体。
- 视频可在本机抽取 4 / 8 / 16 张带时间标记的画面；此方式不包含声音，采样之间的动作可能遗漏。
- 音视频的上下文用量是保守估计，以服务实际返回用量为准。

## Claude Desktop MCP 图片

此前本机和远程 MCP 链路只传任务文字。本版把图片独立保存到任务，任务清单保留图片顺序与名称，Claude 用 `wickrun_read_task_image` 获取 MCP `image` 内容块。图片不作为 Base64 文本塞进提示词。

支持 PNG、JPEG、GIF、WebP；单图 5MB，每任务合计 12MB、最多 16 张。只有对应来源／账号的活动、已领取任务能读取图片。重复任务键会检查图片身份，已取消任务不能继续读取。

更新后需重新连接本机 MCP；使用旧 `.mcpb` 扩展的用户需从新版重新生成并安装。远程 MCP 需部署网页版服务更新。音视频目前不直接经此桥传递：可先转文字或视频抽帧。

本地协议测试覆盖真实 MCP 图片块与隔离；没有使用用户真实 Claude 会话或付费模型做内容识别测试。Windows 文档与浏览器流程已本机验证，macOS、Linux、Android 仍需各自环境验收。


## 即时 Markdown 输入

输入 `**粗体**`、`~~删除线~~`、行内代码或列表语法后，输入框直接显示格式并隐藏标记，没有额外格式工具栏或第二块预览。发送、草稿和模型交接仍以 Markdown 保存，用户消息也按 Markdown 显示。粘贴 Markdown 可立即转换；支持原生撤销。默认 Enter 发送，Shift+Enter 换行；既有发送快捷键设置和中文选词保护继续生效。
