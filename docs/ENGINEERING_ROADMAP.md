## 实施原则

- 主执行器、存储、工具与 UI 的现有路径优先，不引入第二套运行引擎或数据库。
- Agent 在独立目录工作；主负责人核对差异并整合。子任务完成声明不等于验收。
- 程序测试、受控传输测试、真实桌面操作、真实供应商试验分开记录。
- 不自动发布、安装替换日常应用或使用生产项目文件做故障注入。
- 系统沙箱扩展、供应商原生压缩、大规模自动路由、自动经验采用属于条件中的后续决策项：先记录能力边界和对照证据，不凭一轮成功启用。
