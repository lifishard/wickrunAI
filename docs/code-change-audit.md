# 代码改动记录与版本审阅（2.18.11）

入口：对话顶栏的「代码改动」。对话中也会显示可展开的改动摘要。

设置 → 工具 → 代码改动提供两个独立开关：

- **显示代码改动面板与对话摘要**：默认开启。关闭只隐藏展示，仍保留记录；不会关闭审核。
- **逐项修改前确认（可选）**：默认关闭。默认模式直接应用授权目录内的文件编辑，不为每次编辑弹窗；命令、提权等其他权限确认保持有效。开启后，即使对话或协作任务设为「全部放行」，文件修改也需要单独批准。修改设置后从新一轮任务开始使用。

## 默认：先应用，按轮审阅

桌面对话的右侧面板按一轮回答汇总代码版本。同一文件连续多次编辑会展示从本轮首次修改前到最后修改后的净差异。默认在完整文件中保留所有未修改行，把新增标绿、删除内容放在原位置标红，并提供新旧行号；可切换「仅看差异」快速检查。完整内容来自本轮的快照，不会用后来编辑过的磁盘文件冒充历史上下文。按展开的文件读取完整内容，操作明细仍可展开。已生效不等于已审阅，用户可以标记「保留这一轮」，也可以一次回退本轮已记录的改动。任务运行期间禁用版本操作。

完整 UTF-8 快照按内容哈希保存在本机用户数据目录 `code-versions-v1`，审阅状态重启后保留，不依赖 Git 提交，也不执行 Git reset。回退恢复修改前真实的文件内容，包括用户此前尚未提交的编辑。新增文件会删除，删除的文件会恢复；与本轮无关的文件保持原样。

回退先展示反向差异，再检查整批文件当前内容、实际路径、权限和备份完整性。发现后续修改时整批停止；较早版本通常需要先回退同文件的较新版本。同一轮中间存在未记录的编辑，不能合并回退。暂时授权但未加入设置的工作目录，需要先加入设置后才能回退。

跨文件写入不具备文件系统事务原子性。若文件占用或应用中断导致部分完成，持久恢复记录保留，面板显示「继续回退」；新的工具写入被阻止，直到恢复完成。已经回退的执行记录会失效旧验证、清除相关文件交付并添加上下文说明，后续任务必须重新检查文件。

无快照的旧记录仅能查看，不从显示用的片段猜测原文。部分超限文件、外部操作不在回退范围内；按钮明确表示「回退已记录改动」。该面板的整轮版本操作目前面向桌面普通对话；协作记录继续保留差异，尚未提供协作整轮回退入口。快照保存在本机，当前没有自动清理策略，敏感代码也会随完整快照保留。

记录包含路径、时间、工具、修改前后内容哈希、旧/新行号、红绿差异、新增/删除行数，以及待审核、已生效、已拒绝、冲突状态。可按路径筛选或导出文本审计记录。导出文件用于阅读审计，不是可直接应用的 Git patch。

## 审核行为

`write_file`、`edit_file`、`delete_file` 在授权目录内生成修改预览。生成预览不会创建、覆盖或删除目标文件。用户批准后，主进程校验审批令牌、工具参数、授权目录、实际目标路径和文件原文，再执行一次修改。

拒绝或关闭审核框保持原文件。等待期间发生外部修改会阻止覆盖，要求重新读取并审核。审批令牌仅驻留内存、30 分钟有效、单次使用；重启后必须重新生成预览并审核。此可选模式每次文件修改单独批准；生效后的修改也进入版本审阅记录。

严格审核模式目前仅支持 UTF-8 普通文本文件（单文件不超过 512 KB，修改前后合计不超过 20,000 行）。目录、链接、硬链接和二进制文件不作为可审核文本修改。

命令行、本机客户端、文档生成、项目记忆写入、可能间接改文件的电脑/浏览器操作不具备完整的事前文件差异，因此审核模式会阻止这些写入路径。自动命令钩子也会跳过，并明确报告「未执行」，不会把跳过测试当成通过。需要运行命令或使用本机代理时，用户可关闭该设置；这时恢复现有工具权限规则。

## 记录范围

- 文件工具按每次调用的真实原文与新内容记录，不要求项目使用 Git，也不会把任务开始前已有的修改当成本次新增修改。
- 自动模式下的命令、本机客户端和命令钩子按执行前后工作目录快照比较。此记录属于执行时段观察结果，可能包含同一时段的外部编辑，不宣称每一行都由模型直接产生。
- 快照最多扫描 4,000 个文件、16 MB 文本，单文件最多 512 KB / 10,000 行；忽略 `.git`、依赖/构建目录及链接。二进制、非 UTF-8、超限或不可读文件会提示缺失范围，不伪造为完整审计。
- 普通对话、协作 API 文件工具、临时子代理结果和本机客户端运行记录保留差异。Claude Desktop 外部应用自行执行的操作无法完整观察；开启严格审核时不派发工作任务给它。
- 已完成结果随原生执行日志和对话/协作记录保存。应用或操作系统在操作中途崩溃时，原有「结果待核实」恢复流程仍适用；无法保证捕获进程停止后的写入。

验证覆盖真实临时文件的批准/拒绝、参数替换、外部冲突、取消、创建/删除、重启读取日志、命令拦截、钩子旁路，以及模拟模型驱动的完整界面交互。测试没有使用真实模型账号。
