# wickrunAI 2.20.8 — 大文件分块回传

## Added
- 本机 MCP Bridge 新增 `wickrun_upload_artifact`，支持单文件 100 MB、每任务最多 50 个文件/500 MB，512 KB 分块。
- begin/status 返回任务限定的 HTTP 二进制上传通道，避免一次 MCP 调用塞入整个大文件；仍支持 MCP 分块回退。
- 上传可查询缺块、重试、取消，本机重启后续传；完成前校验实际文件 SHA-256。未完成上传预留配额，24 小时过期。
- 超过在线预览上限的文件显示已接收提示，可打开/另存为。旧的 2 MB 快捷发布工具继续兼容。

## Upgrade notes
- Windows 安装版和 Linux AppImage 已安装 2.20.7 时会按自动更新设置获取本版；2.20.6 及更早需要手动安装一次。未安装自动更新版本时，推送 GitHub 不会自动替换旧程序。
- 已使用 2.20.7 MCPB 加载器时，更新应用后重新连接 Claude；仍使用旧扩展时需重新生成并安装扩展，由用户确认 Claude 权限。
- 本机 MCP 文件保存在本机，不依赖 Railway。Claude 云端执行环境不一定能访问本机 HTTP 地址，无法访问时使用分块 MCP 或报告限制。
- 此上限用于产物回传；模型媒体输入限制不变。文件格式沿用此前列表，没有新增音视频产物格式。预览仍最多 25 MB，桌面文本编辑仍最多 1 MB。
- 网页版 2.20.7 同步支持远程 MCP 大文件回传及受限下载；云端文件使用 PostgreSQL 分块存储。

## Verification

- 本机真实 stdio MCP 字节回传、HTTP 分块、重复写入、错误令牌、未完成校验、重启续传、重复完成和保存文件完整性通过。
