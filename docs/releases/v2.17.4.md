# 2.17.4 · 任务优先入口与 429 退避修正

协作任务现在可以直接选择模型和工作方式，为文本任务自动准备可编辑成员与固定流程版本。先准备、再确认开始；高级设置保留成员职责、文件流程、已有流程和设计器入口。已指定负责人或流程的任务沿用原有配置。

修复部分供应商同时返回 TPM/RPM 限流和 insufficient_quota 时被误判为永久额度不足的问题。单一 Agent 与协作空间共享修复；默认 62 秒退避，Retry-After 优先。明确余额耗尽及鉴权错误仍不自动重试。

655 项自动化、类型与构建通过；实际桌面从空团队创建任务，同一路由 429 后等待 62.144 秒自动恢复至 200，再由界面批准交付。证据使用本机合成服务，不能代替真实供应商可用性或新手学习成本评估。

当前为未打包发布的源码更新，包含上一批 2.17.3。文件任务首跑与更直观的角色定制将继续按易用性支线推进。
