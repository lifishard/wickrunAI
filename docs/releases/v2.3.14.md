# 2.3.14 — 会话隔离、两文三语与工作目录护栏

本版把 2.3.1 之后的改动一次收口，重点是**会话之间不再互相占用**，以及界面的**简体中文 / 繁體中文 / English** 三语支持。

## 会话隔离

开新对话时输入框仍被另一条进行中任务占住的问题已修复。运行态按会话分桶：每条会话各自跑各自的路由，互不锁输入框，排队输入只进入自己那条会话的队列。额度限制本来就是按路由（凭据 + 模型 + 端点）计的，这次把运行锁也对齐到同一粒度 —— 用不同路由就各自受各自的限制。同一项目内的会话共享规范、记忆、文档和提示词，但不共享运行队列和额度。

停止、暂停和恢复都只作用于目标会话，后台会话继续跑。

## 工作目录护栏

两条会话同时往同一棵目录树里写会互相覆盖。现在写权限按目录树登记：已有会话占着时，新的一条排队等待并提示是谁在占用，只读运行不登记也不被挡。判定跨平台一致（大小写、分隔符、结尾斜杠）。这条规范同时写进了 `AGENTS.md`。

## 两文三语

界面支持简体中文、繁體中文和 English，在右上角模型标签旁切换，也可在设置里选。

实现上，简体原文就是翻译 key：繁體由 OpenCC 自动转换（台湾用词，如「設定」「搜尋」「預設」），英文查词典，查不到回落简体，界面不会缺字。当前 1596 条英文词条，覆盖界面文案、错误诊断、工具活动摘要、400 排查结论、技能安装反馈和恢复卡片。

发给模型的文字不跟界面语言走 —— 权限申请的工具返回、续跑指令、导出的诊断报告保持简体，因为跟着 UI 切语言会改变模型行为。落盘的执行摘要按生成时的语言保留，历史记录不回溯改写。

## 界面

- 「对话运行方式」入口改成按钮，不再占满一行
- 底部工具条按钮可调密度（紧凑 / 标准 / 宽松），开着配置面板也能排在一行
- 删除会话前需要确认
- 已钉选的会话仍显示在所属项目分组里
- 协作空间的任务通知与单 Agent 一致：需要回答、已暂停、失败、已完成

## 验证

类型检查通过，42 个测试文件共 321 项自动测试全部通过，前端生产构建通过。i18n 另有五项回归守卫：词典无重复 key、诊断文案有英文、已改造文件的每个翻译 key 都有英文、反斜杠正确转义、界面属性里没有漏网的裸中文。

三平台安装包由 GitHub Actions 在版本标签上构建并核验。
