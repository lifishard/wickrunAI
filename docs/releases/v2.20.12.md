# wickrunAI 2.20.12

本次更新加入内嵌管家与模块化办公室，并改善接口兼容性和聊天输出的保留方式。

- **管家**：从自然语言需求开始，协助提出分工、交付要求和验收标准；必要时向用户提问。采用方案创建团队、流程与任务草案，启动仍是单独操作。
- **规范、约束与学习**：支持全局和项目专用 prompt、已选技能、项目记忆及有来源的学习建议。建议经用户采用后保存，技能先成为未启用草案；实际执行权限由程序控制。
- **模块化办公室**：内置 12 个职责模板，可拖入部门并分别配置模型。支持子部门、独立成员实例、整组复制、拆散、合并及模块导入导出。原有工作流编辑器继续保留。
- **接口兼容性探针**：针对 OpenAI 兼容路由发送少量简短请求，验证接受的思考参数格式并缓存结果。按验证结果显示强度、开关或默认模式；不会将参数被接受等同于模型实际推理能力。探针会消耗少量上游额度。
- **输出记录**：正文或思考被替换、重试或重新回答时，旧输出以可展开历史保存，重启后可查看，展示历史不会自动加入模型上下文。
- **会议室**：加入基于客户端连接的讨论、公开提问及有界自动轮流发言。参与者加入一次后可等待下一轮邀请；讨论不代替独立质检与用户决定。

当前管家自动生成流程覆盖文本任务、串行或并行分工、独立文本复核和人工验收。视频处理、外部发布等复杂流程继续通过已有编辑器配置。Task Observer 的学习方法采用内嵌适配，并非其完整运行环境移植。

验证：本地 1005 项自动化测试通过，类型检查、构建及隔离桌面端交互和重启恢复检查通过。真实 SenseNova 模型路由需在用户连接上实测；实际 ChatGPT 聊天本体的接入可用性取决于其客户端连接能力。

角色原文来自 MIT 许可的 agency-agents；学习指导改编自 CC BY 4.0 许可的 Task Observer。许可和来源随应用保留。

使用入口：**找管家 · 说说想做什么**，以及协作空间中的 **管家 / 办公室**。
