# wickrunAI 4.0.0 — 跨账户共享与协作重大更新

跨账户共享与协作覆盖文件、文件夹、对话、项目和工作流。所有权限由账户服务校验：可选查看、评论、编辑，通过链接、指定邮箱或空间成员开放访问。子项继承上级权限。未登录用户可以查看公开内容；所有者可另外开启访客共享评论，访客不能编辑、发群聊消息或创建分享。

共同对话保留发言者账户、时间以及 AI 回复所用的模型；人类消息在左，AI 回复在右。消息采用独立追加和稳定重试编号，避免两人同时发言覆盖彼此。资源编辑使用版本检查，遇到新版本保留未保存草稿。私密与共享注释独立存储，支持资源、文字、对话消息和流程步骤定位，不进入助手上下文或项目记忆。变更和历史版本记录账户、动作、时间。

个人及公司空间现在免费。成员和管理员可以按权限管理共享内容与名单；公司管理员不能访问成员的私人云数据或管家资料。预留个人按月、公司按席位按月的数据模型，未接入收费。Google 登录使用 wickrunAI 账户身份，其他身份提供商复用同一账户层；Apple 登录尚需配置，未启用。

连接是双方接受的交接关系，与共同编辑区分。可以选择工作区或工作流 Agent，传递明确填写的目标、说明和选中的文本文件；接收者打开的是待检查的本地草稿。双方保留自己的流程、模型和工具权限。复制共享工作流产生新的身份，Agent、routine 默认关闭，需要使用自己的接入并手动启用。执行记录保存当次流程快照；后续共享流程修改不会改写既有运行记录。撤销分享、成员权限或连接后，下一次交接重新校验权限。

管家的个人目标、信号、记忆、任务、日志、来源原文、授权和派生会话不进入共享空间。共享不会复制 API 密钥、工具授权或本机路径。

桌面首次登录继续使用这台机器原有的工作区，包括对话、项目记忆、模型配置、流程、执行记录和工具设置。3.0.1 首次登录进入空工作区的情况会在原本机数据仍在、且新账户尚无本地工作时恢复；原目录和空账户目录都保留。后续账户仍各自隔离。个人管家记录绑定到该首次账户时保留恢复副本，不重写其他账户记录。

发布必须包含同版本 Windows、macOS、Linux 安装包和 Android APK，安装包清单及校验值会验证完整性。Android 当前为预览包。

Android 3.0.0 的发布包使用临时签名，原密钥未保留，无法直接覆盖升级到 4.0.0。沿用原应用标识 `dev.anyai.app`，旧版用户需先确认已备份所需数据，再自行卸载重装；未备份的数据会随卸载删除。此过渡方式由用户明确选择。4.0.0 及后续预览包固定签名，发布流程核对证书，密钥缺失或不匹配时停止发布，不生成新的随机签名替代。

Android 发布源码独立固定到同版本的不可变提交及 `android-source-v4.0.0` 标签；主版本清单记录该提交、应用标识、签名指纹和 APK 校验值。九个安装包及 Android 验证记录齐全后才公开版本。

验证：账户服务权限与撤销、并发发言、冲突保留、私密注释隔离、导入和交接、执行记录同步、本机工作区延续均有回归测试；使用独立的本地测试账户验证真实协作界面及手机布局。测试账户仅用于本地验收，不替代真实 OAuth、实际手机或生产 PostgreSQL 测试。
