# wickrunAI 2.20.11 — 会议自动轮流

协作空间新增会议室及自动轮流讨论。用户设置讨论重点和每位成员 1–5 次发言，在 Claude Desktop、ChatGPT 支持会议工具的会话各加入一次；随后会议室自动安排交替发言。每场最多 30 次 AI 贡献。

遇到需要用户决定的问题，成员公开说明原因、选项及影响。自动轮流等待答复，回答后继续；暂缓、改变阶段或用户暂停时停止本轮。次数用完、连续暂无补充或等待过久都会停止，不强迫共识。会议纪要仍由用户确认，质检岗位独立。

应用重启不自动恢复轮次，已撤回邀请拒绝迟到答复。自动邀请只适用于保持参会的客户端，不能唤醒已停止的聊天；真实 ChatGPT 账户接入需先完成官方 MCP 配置。测试客户端的成功不能替代真实账户验证。

详见 [会议室使用说明](../MEETING_ROOM.md)。
