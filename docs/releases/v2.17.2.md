# 2.17.2 · 文本复核、记忆选择和逐路由用量

协作任务新增“生成文本复核流程”。独立成员核对当前答复的版本与原文引用，失败后有限返工；通过后仍由用户验收。纯文本复核不能替代文件变更检查，也不能仅凭引用证明外部事实。

项目记忆支持事实、偏好、经验分类，项目通用或任务关键词范围及过期时间。运行详情显示选入/排除原因，选入内容最多 6000 字符；已开始任务沿用冻结快照。候选仍须验证和采用。

协作统计按派发时的连接/模型汇总完整逐请求用量，保留未知和历史缺口，导出包含脱敏路由汇总。不会将同一任务总量重复算到每个模型，也不推算货币价格。

实际桌面验收还发现生成流程默认时长可超过项目上限，本次让新生成的时长和 token 预算适配项目设置。

验证：638 项测试通过，类型检查和生产构建通过；独立 Electron 验收跑通文本失败、返工、新版本通过、界面批准，并核对记忆选择与用量持久化。详见 [验收记录](../acceptance/2.17.2/README.md)。受控 HTTP 响应只证明工程链路，此前误选两条付费路由，分别返回 500/402；用户指定免费路由的真实任务与策略质量试验尚待完成。本次未打包、未发布。
