# wickrunAI 2.20.16 — 管家统一安排协作工作

管家可以依据用户目标创建实际团队、完整工作流和任务，并从对话中的操作入口安排执行和会议。用户不必先学会连流程图，也不必自己拟完交付要求和验收标准。

## Added
- 读取现有项目、成员、流程、任务、运行、会议、可用模型、工具和技能；根据真实目录生成安排。
- 创建或调整部门和独立成员、配置模型与工具、编排全部十种流程节点、条件分支、并行汇合及有界返工；生成任务依赖和定时草案。
- 部门移动、合并、拆散、复制、模块保存与组装，以及工作流归档和恢复。
- 采用后提供真实操作：运行前检查、暂停/继续/停止、补充任务要求、启停定时、创建客户端会议、自动轮流和邀请发言、检查文件差异。
- 保存安排前检查项目配置是否变化；操作回执随记录持久化，未知结果不自动重复提交。

## Fixed
- 明确要求安排工作时，模型只给口头建议会触发一次结构化修正。
- 复杂管线可由管家直接生成，不再限定为固定的文本讨论模板。
- 复用角色模板时独立建立复核实例，避免执行者复核自己；原始材料随任务保留。

## Breaking changes
None. 旧管家方案仍可查看和采用，已有运行快照保持原样。

## Upgrade notes
- 采用安排与启动任务分开。定时草案初始停用；启动走已有运行前检查。
- 管家复用已配置的模型、工具、技能和目录权限。提问、验收、目录授权、文件合并和纪要确认继续由用户决定。
- ChatGPT / Claude 客户端本体参与会议，仍需首次连接并加入。API 模型讨论使用工作流。
- 2.20.7 及之后的支持安装包可从设置检查更新；更早版本需手工安装一次。数据目录继续使用 `anyai`。
