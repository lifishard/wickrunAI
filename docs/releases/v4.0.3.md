# wickrunAI 4.0.3 — 启动提速、稳定第三方客户端、云文件库，Android 改由 CI 签名

4.0.2 只是内部版本，没有单独发布：它的全部内容（稳定第三方客户端、视频与大文件输出、云文件库与 R2 共享文件）并入本版，详见 [4.0.2 说明](v4.0.2.md)。本版在它之上新增：

**启动与稳定性**

- 启动不再读入全部历史执行记录：此前每次打开都会读入所有任务的完整模型上下文（累计可达数百 MB，要数秒并占用上 GB 内存，历史很大时窗口会长时间空白）。现在启动只读取每个任务的摘要（约为原来的二十分之一），打开某个对话、继续任务、交接上下文或发送消息时才读取该对话需要的完整上下文；保存摘要不会覆盖已存的完整上下文。
- 修复进度快照写盘的一个并发竞态：两次重叠的写入共用同一个临时文件，偶发读到被截断的记录。

**Android 预览版：签名与发布流程变更**

- Android 预览版不再使用本机签名的 APK，改由 GitHub Actions 从固定源码标签（`android-source-v4.0.3`）构建，并用 CI 持有的新密钥签名；公开的证书指纹（SHA-256）固定在 `config/android-release-source.json`，构建出的 APK 证书不一致就不会发布。
- **新密钥与 4.0.1 的 APK 签名不同，Android 不允许覆盖安装：手机上已装旧版的需要先卸载（先在应用里备份数据）再安装 4.0.3。** 之后的版本都沿用这把密钥，可以直接升级。
- Android 不再阻塞桌面发布：Windows、macOS、Linux 三个平台构建成功即发布；Android 构建或签名失败时，Release 页会写明“Android 预览版暂未随本次发布”，问题修复后用 Release Android 工作流（或重新运行失败的任务）补发，APK 追加到同一个 Release，已发布的桌面文件不会被改动。
- Android 预览版的功能与 4.0.1 的 Android 线一致；桌面 4.0.2 起的改动（第三方客户端、媒体输出、云文件库）暂未并入 Android 线。

**已知限制**

- 同 4.0.2：云文件库内容不使用端到端加密；共享群聊的消息数（1000 条）与单条大小（500 KB）限制未改动；真实 Cloudflare R2 与真实 Grok CLI 的端到端运行需在发布后用真实账号验收。
