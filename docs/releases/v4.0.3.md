# wickrunAI 4.0.3 — 启动提速、稳定第三方客户端与云文件库

4.0.2 为内部版本，没有单独发布，其全部内容并入本版，逐项说明见 [4.0.2 发布说明](https://github.com/lifishard/wickrunAI/blob/main/docs/releases/v4.0.2.md)。

启动不再读入全部历史执行记录。此前每次打开都会读入所有任务的完整模型上下文，一份长编程任务可达 10 MB，累计数百 MB，历史很大时窗口会长时间空白并占用上 GB 内存。现在启动只读取每个任务的摘要，体积约为原来的二十分之一；打开某个对话、继续任务、交接上下文或发送消息时才读取该对话需要的完整上下文。保存摘要不会覆盖已存的完整上下文。同时修复进度快照写盘的并发竞态：两次重叠写入曾共用同一个临时文件，偶发读到被截断的记录。

接入 Grok、Kimi、Codex 等官方客户端执行长任务时，进度合并写盘，界面事件按 100 毫秒合并，文字和工具状态不丢失，窗口不再卡死。关闭或停止对话时结束客户端整个进程树。Grok 连续 15 分钟（可在运行设置里调整）没有动态时停止等待，保留已有输出并提示如何继续。

客户端在工作目录生成的视频、音频、大图和压缩包，以及 API 模型在回复中返回的图片、语音和视频，统一保存为文件并列入本轮产物，任务中途出错也会列出。视频和音频从本机磁盘流式播放并支持拖动；供应商下载链接只接受 https，拒绝本机或内网地址，单文件上限 2 GB。

新增“设置 → 云文件”：上传、在线播放、下载和删除自己的文件，免费 1 GB、付费 10 GB，单文件最大 5 GB。共享文件的新上传改存同一对象存储，与云文件库共用额度；每次下载先按共享权限校验，再签发 15 分钟有效的链接，撤销共享后旧链接立即失效。端到端加密的共享项目仍为 100 MB 上限。

Android 预览版改由发布流水线从固定源码标签 `android-source-v4.0.3` 构建，并用流水线持有的新密钥签名；公开证书指纹固定在版本清单中，证书不一致即拒绝发布。桌面三平台构建通过即发布，Android 构建或签名未完成时，发布页会注明并在完成后追加 APK，已发布的桌面文件不做改动。

新密钥与 4.0.1 及更早的 Android 预览包签名不同，无法覆盖安装。请先在应用内备份需要的数据，再卸载旧版、安装 4.0.3；之后的版本沿用这把密钥，可直接覆盖升级。应用标识仍为 `dev.anyai.app`。本版 Android 功能与 4.0.1 的 Android 线一致，桌面 4.0.2 起的改动尚未并入。

已知限制：云文件库内容不使用端到端加密；共享群聊的消息条数（1000 条）与单条大小（500 KB）限制未改动；真实 Cloudflare R2 与真实 Grok CLI 的端到端运行需在发布后用真实账号验收。

验证：类型检查及 1266 项自动回归测试通过；发布前以只构建模式完整跑通 Windows、macOS、Linux 与 Android 构建，Android APK 的签名证书与固定指纹一致。物理手机安装未在本次自动流程中覆盖。
