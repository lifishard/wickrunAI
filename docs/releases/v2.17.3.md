# 2.17.3 · 重复返工停止与恢复

独立复核连续两次失败时，如果收到的文件或文本内容、任务要求和检查证据没有变化，流程会停止自动返工并等待用户核实。当前失败的产物引用、复核意见和证据保留；明确重试会重新检查一次，重复失败仍停止。通过恢复入口接受后，最后的交付仍需用户验收。

这项检查忽略新生成的调用编号、版本编号和时间戳，按实际文件内容哈希、文本摘要及读取/引用内容判断精确重复。内容、要求或证据变化时继续原有有限回路；无法可靠对齐证据时只沿用原有次数上限。这不是语义等价或模型质量判断。

明确重试时使用新的复核检查点，修复真实桌面验收发现的旧、新 JSON 拼接问题；旧回复与请求用量保留，普通中断接续不变。新增用户补充要求也会纳入停滞比较。

工程验证：646 项自动化测试全部通过，类型检查及生产构建通过。实际 Electron 界面跑通两轮停滞、重载后单次重试再次暂停、人工接受及最终交付批准；5 个本机受控请求报告共 1000 tokens，没有第三轮执行。这不代表真实模型质量或实际进程重启已验收。证据见 [验收记录](../acceptance/2.17.3/README.md)。既有大包提示保留。本版源码尚未打包、安装或发布；用户已安装并发布的是 2.17.2。
