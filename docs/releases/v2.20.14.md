# wickrunAI 2.20.14

修复新增功能在英文界面中混用中文的问题，并把办公室角色说明放到角色列表右侧。

- **语言切换**：找管家、代码改动、角色调用、管家设置、办公室、角色与部门库、会议室和请求兼容性入口接入简体、繁体、英文显示；补齐按钮、分类、状态、提示与相关错误文案。
- **角色名称**：全部 279 个内置角色提供中文显示名称；英文使用来源名称。搜索可使用中文或英文名称。用户自定义名称、原始职责 Prompt 和已有记录保留原内容，来源简介与 Prompt 明确标为原文。
- **右侧说明**：点击角色名称，在列表右侧查看说明。正文独立滚动，面板高度适应窗口；收合保留选择，可用明确的展开按钮重新打开。展开时部门区仍可向下访问，收合后恢复原来的部门布局。
- **验证**：1017 项回归测试通过，生产构建通过。隔离 Electron 客户端检查三种语言、1440/1000/720 宽度、键盘收合与展开，以及已有部门的可达性。
