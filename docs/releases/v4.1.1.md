# wickrunAI 4.1.1 — 安装包改由公开发布仓库提供，覆盖安装不再报错，许可变更

## 安装包与更新改从公开发布仓库获取

从这个版本起，安装包发布在公开发布仓库 [wickrunAI-releases](https://github.com/lifishard/wickrunAI-releases/releases)。应用检查更新、[网站下载页](https://wickrunai.com/download) 都从这里读取，不再依赖代码仓库是否公开。

- 4.1.0 及更早的版本会照常收到 4.1.1 的更新提示；装上 4.1.1 之后，后续更新自动改走公开发布仓库，不需要手动操作。
- 发布仓库只追加、不替换：已经公开的安装包不会再被改动；之后补上的 Android 预览版只会新增到同一个版本里。
- 下载页优先使用公开发布仓库；如果某个版本还没同步过去，会暂时从原来的地址提供，不会显示空白。

## 覆盖安装不再报 “Failed to uninstall old application files: 2”

原因是灯芯AI 为浏览器工具启动的专属 Chrome 窗口：它在灯芯AI 退出后仍会运行，而旧版本让它在安装目录里启动，Windows 因此无法替换这个文件夹，安装程序在卸载旧文件时停下。

- 灯芯AI 和它启动的专属浏览器不再把安装目录当作工作目录。
- 安装和卸载开始前，安装程序会关闭用专属配置（`chrome-profile`）启动的浏览器窗口；你自己平时用的 Chrome、Edge 不受影响。
- 如果仍然看到这个错误，多半是有其他程序正在使用安装目录（例如把该目录挂载进其他应用）。关掉它后重新运行安装程序即可，你的对话和设置保存在别的位置，不会丢失。

## 许可变更

- 自 4.1.1 起，wickrunAI 为专有软件，可按 wickrunAI 软件许可免费使用；许可全文在安装目录里的 `LICENSE.txt`。Windows 安装程序会先显示许可页，点「我接受」后继续安装；自动更新不会再次询问。
- 4.1.0 及更早版本以 Apache License 2.0 发布，依该许可取得的副本仍适用 Apache-2.0。
- 应用中使用的开源组件按各自许可证授权，完整清单和许可证全文在安装目录里的 `THIRD_PARTY_LICENSES.txt`，网页版的清单见 https://wickrunai.com/THIRD_PARTY_LICENSES.txt 。
- 问题反馈改到 [发布仓库的 Issues](https://github.com/lifishard/wickrunAI-releases/issues) 或 admin@wickrunai.com；安全问题请走邮件。

## 其他

- 说明文档更正：自动更新默认开启（启动约 20 秒后、之后每 4 小时检查一次，可在设置里关闭）；网页版会用你自己的密钥把请求转发给你选的服务商，不保存请求内容。
