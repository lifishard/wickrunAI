# wickrunAI 2.20.6 — Claude 图片链路验收与附件重试修复

修复 Claude Desktop 扩展包的工具清单缺少图片读取能力。任务原图传递沿用 2.20.5；本版本让扩展安装说明明确包含 wickrun_read_task_image。

## Fixed
- 在 MCPB 工具清单中声明图片读取工具，避免扩展描述和实际服务能力不一致。
- 修复「重新生成」丢失原问题图片、音频、视频附件与引用范围的问题。
