# wickrunAI 4.0.4 — 保存失败后能自行恢复

修复桌面端本地数据一次保存失败后再也存不了的问题。Windows 上替换数据文件 store.json 时，杀毒软件或索引服务可能正在扫描刚写完的文件，系统会短暂拒绝重命名（EPERM）。此前写入线程遇到任何一次失败都会永久标记为失败，之后所有设置和对话的保存都返回同一个错误，直到重启应用；“保存并重启安装”需要先保存，因而也无法安装已下载的更新。

现在替换文件遇到这类暂时性拒绝会自动重试，最长约 3 秒。重试后仍然失败时只拒绝这一次修改，内存中的数据与磁盘文件保持一致，下一次保存会重新尝试。只有检测到数据文件被其他程序改动时才停止写入，避免覆盖对方的修改，这一保护不变。

Android 预览版与 4.0.3 相同，由 CI 使用同一把密钥签名，可直接覆盖安装 4.0.3。

验证：新增两项回归测试，分别覆盖单次写入失败后后续保存恢复，以及 Windows 暂时性拒绝的重试与非暂时性错误立即报错。
