# wickrunAI 2.20.26：可暂停的等待、固定复制按钮、输出卡片与可选追问

## Fixed

- 请求准备、模型无响应、本机客户端等待期间保持「暂停」可用；取消等待并保留已有内容，迟到回复不会覆盖后续请求。重启后遗留的思考状态恢复为暂停记录。
- 代码复制按钮固定在滚动区域外的右上角，正文和输出面板的复制按钮常驻。代码按原始文本复制，保留真实空格、Tab 与缩进；粘回输入框时保留代码格式，普通 Markdown 列表保持原有行为。

## Added

- Chat 和 Work 都向模型提供应用内输出工具。成品文本显示为可复制卡片，此类展示不需要批准；文件修改、命令与实际操作的授权机制保持有效。
- AI 已输出的延伸问题可以成为逐行的可选追问。点击后在当前会话发送该问题，保留尚未发送的草稿和附件。展示追问不额外调用模型；纯输出工具批次无需再请求模型确认。真正需要用户补充信息或决定的问题保持原有交互。
- 本机模型连接与网页中继支持同样的文本输出和追问呈现。

## Upgrade notes

更新并重启应用后生效。原会话及执行记录保留。网页端同步本次交互能力。

## Verification

发布前执行类型检查、回归测试、生产构建，以及 Chat / Work 的浏览器交互验收。模型协议使用确定性测试响应验证，未使用真实供应商额度逐个测试模型。

## Downloads

Windows 安装版/便携版、macOS Intel/Apple Silicon DMG/ZIP、Linux AppImage/DEB 位于本稳定版 Release；Android APK 沿用独立的 `android-preview-v2.20.26` 预览发布渠道。Android 真机安装与移动系统行为不以浏览器尺寸测试代替。
