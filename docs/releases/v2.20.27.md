# wickrunAI 2.20.27：主动管家

管家现在可以在明确开启后，从对话与获准的设备活动中整理需求线索，在所选常开电脑上持续分析、研究，并生成早晚简报。它提出的目标和技能仍由你审阅；推测不会自动变成你的决定。

## Added

- 「今日管家」集中显示线索、目标推测、简报、技能草案、来源状态和活动记录。可以确认、纠正或否定目标，也可以对结果留下「有用 / 不喜欢 / 不是我的需求」反馈。
- 可选择模型路由组或已连接的订阅客户端，设置每日用量上限、时间、时区与执行电脑。同一账户的手机可查看、补充需求与提交工作；定时分析、公开资料研究和简报由选定的常开桌面版执行。电脑离线时持续任务不会在云端代跑。
- 外部来源逐项开启，并要求采集设备再次授权和限定范围。桌面版可通过本地浏览器扩展读取获准域名当前视口的文字；Windows 读取白名单前台应用的可访问文字，macOS 使用辅助功能文字，Linux X11 只读取窗口标题。Android 预览客户端提供经系统授权的可访问性文字与主动分享入口；公开 HTTPS 链接也可主动提交。
- 采集原文保留在设备本地，不进入共享管家记录。默认的增强理解方式会把有限、尽力脱敏的可见片段交给所选模型提取主题；也可改成仅在本机提取主题。跨设备同步的是有界摘要、推测、简报、反馈和状态。现有 API 密钥加密同步机制没有改动。
- 隐私规则可按设备设置拒绝名单、排除词和仅加密保留词；拒绝优先于白名单。身份验证内容直接丢弃，联系人与财务字段默认脱敏，健康内容默认排除。桌面原文使用操作系统安全存储加密；不安全的 Linux 密钥后端不写入明文。修改规则会停止管家 Work 并清理不再允许的旧线索。
- 可暂停或关闭采集与后续请求，逐项撤销来源。管家的需求理解和研究生成待核对的文字与来源；确认或纠正的目标可手动交给现有 Work。另可单独开启「日常自动执行」，让合适的候选目标在独立 Work 工作区先产出可审阅的文件、草稿或原型。每个目标只自动派发一次，同时只运行一个，并受每日次数上限约束。技能草案审阅后以停用状态加入技能库。
- Work 可提取 PDF、DOCX、XLSX、XLSM、XLS、PPTX、POTX 中可解析的文字和表格；旧 `.ppt` 及扫描版 PDF 需要先转换或 OCR，不能把空白提取结果当作已读懂附件。

## 范围与限制

这不是对所有网站或应用的历史记录读取。浏览器扩展只在用户明确允许的域名运行，不能识别 Instagram 的完整收藏、转发或 Reels 历史。没有实现屏幕 OCR、视频或音频理解。Android 的实际可读文字受系统权限、应用无障碍实现和设备限制影响；发布前仍需真机验收。脱敏是尽力处理，不保证所有个人信息都能识别。

管家的后台认知与研究运行器不替用户下单、谈判、发送消息或操作账户。自动 Work 的 API 文件工具限于独立工作区，不能使用命令、浏览器、MCP、代理或外部发送。Codex 的自动任务使用受限工作区沙箱；Kimi/Grok 只自动放行范围内文件编辑；Claude Code 自动任务只能提供无工具的只读草稿。文本文件可依版本记录逐行查看并回退，16 MB 以内的 DOCX/PDF/XLSX 等二进制文件可通过完整字节快照回退，但不能逐行预览；若快照失败会提示不能自动回退。手动 Work 沿用原有操作权限与审批。管家认知每日用量上限与普通 Work 模型用量分开，自动 Work 另有限定的每日次数。投资简报是需要核实的研究资料，不是交易执行或法律保证。与 Grok Bot、Claude Cowork 和 ChatGPT dots 的云端电脑、广泛连接器及跨应用代操作相比，本版聚焦用户自有常开电脑、明确来源授权和可审阅的需求发现。技术与产品边界见 [主动管家说明](../PROACTIVE_BUTLER.md)。

## Upgrade notes

主动管家默认关闭。更新后需主动选择执行电脑、模型与来源权限；只配置浏览器白名单还需安装并启用本地扩展。原有聊天、团队任务和 API 密钥设置继续使用现有机制。
