# v2.17.1 · 复核路径校验与逐请求路由归属

复核通过现在必须读取接收隔离区内的完整目标路径。其他子目录的同名文件、其他隔离区文件、POSIX 大小写不同的文件不能替代产物证据；没有版本化产物的文件复核也不能返回通过。已有 2.17.0 的产物版本与接收副本完整性检查继续执行。

普通、最终和压缩请求保存派发时的连接和模型，团队观测为每个请求记录脱敏路由、用途及已知用量。旧记录无法补出的身份和用量继续保留未知。任务级路由排行榜仍不拆分多路由总量，避免整次成本被重复归到每条路由；没有引入货币价格估算。

新增实际运行器的组合回归：用户纠正、至少两次语义压缩、持久化重载、连接与模型切换、原始证据检索、成功写入不重做、未知动作暂停后明确跳过。模型回答与工具边界受控，不能据此宣称真实摘要语义保真。

增加固定合成 CSV 试验题与离线验收报告工具，独立检查输出字段、汇总和输入字节不变。三种流程的真实模型对照尚未完成：实际桌面请求的 Luna Max 网关返回沙箱配置错误 500；另一固定 Luna 路由的连通性请求返回 402。两次失败均保留证据，不归为质量样本或零成本成功。

全量自动化 617/617、类型检查与构建通过。细节与桌面证据见 [本批验收报告](../acceptance/2.17.1/README.md)。当前仅更新源代码，未打包、发布或替换日常安装。
