# wickrunAI 2.20.7 — Claude 任务指令、文件回传与自动更新

## Added
- Claude 任务旁提供完整专属指令，可一键复制或展开手动复制；指令绑定任务 ID，防止领取其他排队任务。
- 新增 MCP 工具 `wickrun_publish_artifact`，接收真实图片和文档内容，显示在成果列表。支持图片预览、另存为；单文件最多 2 MB、每任务 10 个文件且总计 8 MB。重复提交相同请求键不会重复保存。
- Windows 安装版和 Linux AppImage 默认自动检查、下载 GitHub 正式版，正常退出时安装；关闭窗口继续后台任务。设置内可关闭更新、手动检查或保存后重启安装。
- 主分支推送递增版本号并通过 CI 后自动创建不可变标签、启动三平台构建并发布。未增加版本号的普通提交不会覆盖既有版本。

## Fixed
- 退出前保存当前输入草稿和会话记录；任务运行中拒绝主动重启安装。
- 新 MCPB 加载应用维护的桥接服务，后续应用升级后重新连接 Claude 即可加载更新。

## Breaking changes
None.

## Upgrade notes
- 2.20.6 及更早桌面版本需先手动安装本版一次，之后支持的平台会自动更新。
- 本版新增文件回传工具：在连接设置中重新生成并安装 Claude 扩展一次，再重新连接 Claude。旧 2.20.6 扩展不会自行获得新工具；扩展权限仍由用户在 Claude 确认。
- Claude Desktop MCP 没有在本版实现后台自动唤醒或额度查询。已实现完整指令的一键复制保底；Claude 的任务执行仍需在官方应用发送指令并允许连接器。
- 文件需由 Claude 调用回传工具上传实际内容；单纯回复 sandbox 路径不会复制文件，不能把“无法回传”报告为已回传。
- 当前 macOS 发布包未签名，便携 Windows 和 Linux deb 同样需到发布页下载安装。它们只检查版本，不自动安装。
- 数据目录保持 anyai。下载与安装失败会显示原因，不自动重启正在工作的应用。

## Verification
- 本地 stdio MCP：专属任务领取、PNG/Markdown 实际字节往返、重复请求、任务及来源隔离、完成后的拒绝写入通过。
- 远程 MCP 与网页版另有文件接收、账号隔离及浏览器预览/下载测试。
- Windows 本地完整回归与类型检查通过。新文件回传尚未通过真实 Claude 模型会话验收；自动更新安装尚未在其他用户设备完成跨版本验收。
- macOS / Linux 构建由发布工作流验证，未在本机运行。
