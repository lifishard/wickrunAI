# wickrunAI 2.20.13

角色库扩展为完整目录，并加入跨项目部门库和对话内的角色子代理分派。

- **完整角色目录**：内置 agency-agents 固定版本的全部 279 个角色，覆盖 18 个中文分类。保留角色原始名称、职责正文与来源；此前 12 个角色的中文名称继续保留。
- **搜索与批量操作**：按分类、名称或职责关键词搜索；可勾选筛选结果批量加入部门，也可一次导入多个 Markdown 角色。导入前展示角色清单及跳过原因。
- **来源更新**：检查 GitHub 上游新版本，列出新增、更新和移除的模板，查看前后职责正文并选择采用。失败或取消保留原库；已有成员和保存的部门快照不会被自动覆盖。
- **部门库**：提供内容工作室、产品研发部、市场增长部、独立质检部，以及 18 个按专业分类的组合。个人部门库可跨项目复用，支持批量导入部门模块。新实例独立配置；跨项目复用需重新配置模型和工具，组装不会启动任务。
- **对话内角色协作**：在“调用角色”中搜索并勾选多个角色，然后启用协作；也可在消息里明确要求使用子代理或让多个已命名角色分工。主模型能搜索角色目录、分派带独立职责的子任务、收回结果并汇总。
- **可查看的子任务**：显示角色、状态、任务说明和完整结果。默认最多四次派发、同时两个；手动选择角色时按人数配置次数，最多八次。子代理不能继续派发子代理，不因角色选择扩大工具或编辑权限。

独立子代理调用使用支持工具调用的 API 模型。外部客户端使用其自身提供的协作能力，本版不声称能替任何外部聊天客户端开启其未提供的能力。

验证：1014 项回归测试通过；独立角色职责实际进入子代理请求，主模型等待子任务结果后交付的集成测试通过。隔离 Electron 客户端验证完整目录、批量导入、来源变化逐项采用、跨项目部门复用及多角色选择。更新来源与模型测试使用可控模拟，未以此宣称真实模型输出质量。
