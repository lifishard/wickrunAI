# wickrunAI 2.20.17 — 可编辑的岗位操控面板

管家的结构化方案现在可以直接操作：左侧选岗位，右侧修改名称、职责、所属部门、模型与思考强度。用户不用把每次人员和模型调整都重新写成一段提示词。

## Added
- 岗位面板支持从角色模板或自定义新增岗位；能勾选参与的讨论并选择步骤负责人。
- 移除岗位时可以明确接替者，并检查讨论人数与必需分工；已有成员及历史记录保留。
- 思考选择读取当前接入的兼容性结果：已验证的档位、仅开关或上游默认分别显示。换模型先使用默认设置，避免沿用不支持的请求。
- 编辑即时显示并自动保存为草稿，采用后才更改协作空间；保存失败可重试，未保存成功不能采用。
- 已采用方案可以建立可编辑的后续安排：复用现有成员和最新流程，保存新流程版本并创建后续任务。原任务和运行快照保留，会议与操作不会重复执行。

## Fixed
- 方案不再用长篇成员清单代替配置控件；方案原始说明、流程细节及工具权限可展开查看。
- 岗位引用、任务负责人和定向消息在接替时同步更新，防止留下悬空分工。
- 下拉框使用稳定的可访问名称；桌面与窄窗口均可直接选择和编辑岗位。

## Breaking changes
None. 2.20.16 的结构化方案在更新后直接显示为面板。更早的固定方案保留原有兼容视图。

## Upgrade notes
在设置中检查更新至 2.20.17。采用安排与启动任务继续分开；修改已采用方案通过“调整为后续方案”进行。讨论不代替独立质检和用户验收。数据目录继续使用 `anyai`。
