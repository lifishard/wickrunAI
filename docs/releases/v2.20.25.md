# wickrunAI 2.20.25：看图能力按实测判断，请求格式检测一并测看图写法

## Fixed
- kimi-k3、deepseek-v4.1-flash 等能看图的模型，发图时被拦下并提示“当前模型不支持图片”。原因是 SenseNova 的模型列表把它们登记成只收文字，而看图检测又常常测不出结论：检测只给 32 个输出 token，思考型模型全花在思考上，正文为空。现在只凭模型列表的登记不会再拦图片，只有实测确认不能看图、或你在对话设置里手动配置过，才会拦下。
- 看图检测并入请求格式检测，关掉思考、给够输出长度，并依次试两种图片写法（`image_url:{url}` 和 `image_url:"data:..."`）。哪种写法被接受并答对，以后发图就用哪种。
- 只把明确提到图片的拒绝算作“不能看图”，“某个参数不支持”之类的 400 不再误判。旧版本存下的看图结论作废，重新检测一次。

## Verification
静态检查、类型检查与全部回归测试通过。新增测试覆盖：检测关掉思考并按探测到的输出字段给 512 个 token；第一种写法被拒、第二种被接受时记录第二种；参数类 400 不算“不能看图”；请求按记录的写法改写图片字段；只有实测“不能看图”才拦截。未在真实的 SenseNova 上验证。
