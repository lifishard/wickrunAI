# 2.17.5

协作空间可以从一句尚未想清楚的想法开始。选择“帮我理清想法”，两位助手会探索方向、整理问题和下一步建议；可以补充讨论，也可以编辑建议后建立新的执行任务。无需先构思工作流或填写完成标准。

选择协作方式时增加真实流程预览，展示助手分工、步骤、返工及分支。已有保存版本与未发布草稿明确区分，运行前看到的图与所选版本一致。原有高级设置和设计器保留。

修复继续梳理时旧轮待验收占住单并发名额的问题；下一步操作会结束本轮规划，但不会批准或启动建议中的实际任务。新任务保留想法来源，模型建议不能自动带入工具或接入配置。
