# wickrunAI 2.20.10 — 协作空间会议室

新增用户主持的会议室：共享议题与材料、分阶段讨论、引用回应、建设性异议、暂无补充，以及独立保留的会议纪要。Claude Desktop 和 ChatGPT 通过会议 MCP 工具参与自己的会话。

成员可以在会议途中和形成结论前向用户提问。问题和答复进入公开会议记录，未回答时阻止依赖决定的继续与结论确认；允许主持人明确邀请讨论独立事项。用户可以自由回答或暂缓。

纪要须由用户确认，保留共识、分歧、未决问题和行动建议。会议不改写或代替质检岗位；转为后续任务只创建待编辑草稿。

ChatGPT 需要另外完成官方 MCP 接入，支持的账户、会话模式和客户端需实测。本版不会自动唤醒普通聊天、不会用 Codex/API 冒充 ChatGPT、未宣称真实账号无人值守会议已经通过。

使用方式、连接步骤、存储范围与验证边界见 [会议室说明](../MEETING_ROOM.md)。
