# 2.17.8：分别配置助手与复用团队方案

新文本任务的准备页现在支持分别设置执行、讨论、复核或探索助手。默认仍可直接选模型准备任务，需要定制时再展开。

- 每位助手可选择不同接入、模型和职责，也可从项目已有成员复制模型与职责。创建本任务独立配置，原成员及旧运行保持不变。
- 统一模型修改会应用到所有助手；个别助手可在下方再次调整。实际安排列表与流程预览同步显示模型、职责和工具说明。
- 可把工作方式及角色配置保存为项目内团队方案，下次载入后调整。支持另存不同名称和删除；载入、保存、删除均不会自动执行任务。
- 想法梳理的职责编辑使用自然语言，系统仍保留结构化建议要求。文本复核仍需引用实际产出并经过人工交付验收。

本轮面向尚未准备流程的新文本任务；已有复杂流程仍使用原成员及流程编辑入口。复制与方案复用不启用文件、命令、技能或自动换路由。每项目最多 20 个团队方案，名称不可重复。

740 项自动化、正式类型检查、快速检查、生产构建及独立 Electron 操作验收通过。实际请求使用本机合成回复，未验证真实模型质量。详见 [验收记录](../acceptance/2.17.8/README.md)。源码版本已更新；本轮未打包或发布。
