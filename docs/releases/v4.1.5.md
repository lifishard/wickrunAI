# wickrunAI 4.1.5

本版补齐新增云文件的实际内容核验。桌面和网页不再只凭“上传完成”或大小相同判断文件已经正确保存。

- **核验通过才完成。** 上传后显示“正在校验云端内容”，服务端逐块读取云端实际字节，检查大小和内容身份；失败的文件不能作为可用成果发布。
- **共享文件也按实际字节恢复。** 同名、同大小和同修改时间不足以复用上传。加密项目核验密文并保留原有文件校验字段；加密文件仍限 100 MB。
- **失败可以重新上传。** 核验失败后安全清理旧会话，再选择同一文件重新上传。旧服务端缺少新协议字段时明确提示，不降级为未经核验的成功。
- **取消状态更准确。** 停止等待、文件禁止发布、云端删除分别处理。云端完成请求结果未知时，界面保留待清理说明和占用额度，不凭取消函数返回或超时宣称对象已删除。
- **大文件有界处理。** 新上传统一采用分片协议，校验流在数据库事务外读取并限制并发；账户切换、核验超时和迟到响应不能把旧任务变为成功。

内容核验会额外读取云端对象，大文件因此需要更多等待时间和读取流量。旧版已经上传的文件不会追溯获得已验证标记。本批已覆盖本地协议、数据库和故障测试；真实 R2 bucket 与 5 GiB 实传仍待验收，合成数据流测试不能替代这些证据。

Android 同步为 4.1.5，继续保留上一版的同意、采集与暂停保护。Android 本批没有新增云文件库上传入口；APK 继续由 CI 使用固定证书签名。
