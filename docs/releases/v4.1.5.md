# wickrunAI Android 4.1.5

本版 Android 与桌面、网页同步到 4.1.5，功能承接 4.1.4。

- 保留管家暂停后的派发保护、暂停请求状态提示，以及恢复前的明确操作要求。执行电脑在线仍不代表任务已经停止。
- 保留 Android 数据范围同意、来源撤权、授权代次和原生采集保护。
- Android 当前没有本批云文件库上传链路，因此本版仅同步版本，未移植云文件库或新增云端对象字节验证功能。

Android APK 继续由 CI 构建和签名，applicationId 与固定证书保持不变。
