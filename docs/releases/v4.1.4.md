# wickrunAI Android 4.1.4

本版改进管家暂停与来源授权的可靠性，并对齐桌面和网页版本。

- 暂停立即阻止后续派发；暂停前开始的采集或准备不会因随后恢复而重新生效。
- 界面显示暂停请求转交中、已记录或失败；执行电脑在线不代表任务已经停止，远端结果尚未确认时如实提示。
- 补充数据范围同意保留已有暂停；撤回来源授权失败时仍关闭本机授权和派发，等待用户处理。
- 保留 Android 来源授权版本、授权代次、原生采集串行控制和迟到结果保护。手机可提供授权线索、提交需求及控制 Work，实际执行仍由选定电脑负责。

日常 Butler 保持单模型。本批未移植云文件库，也未启用真实收款。Android APK 仅由 CI 构建和签名，applicationId 与固定证书不变。
