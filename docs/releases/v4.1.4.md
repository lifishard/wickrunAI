# wickrunAI 4.1.4

本次继续修复管家停止请求与共享文件交付的可靠性。

- **暂停立即拦住后续派发。** 正在准备的模型、工具、Work 和子任务在派发前重新核对暂停与账户状态；恢复后也不会复活暂停前的旧准备。迟到创建的 Work 保留记录并接收停止请求。
- **停止状态如实显示。** 界面区分请求转交中、已记录和失败；执行电脑在线不代表任务已经退出。已经开始的工具保留结果未知的提示，避免把取消请求当成成功撤销。
- **授权变更不会偷偷恢复管家。** 补充同意保留明确暂停，用户选择恢复后才继续；撤回来源授权失败时继续阻止派发，并显示需要处理。
- **共享文件与成果一起保存。** 配套网页服务修复文件引用与过期清理的竞争，在保存前核对对象存在与大小；删除中断的文件保持不可引用状态并可重试清理。
- **上传时精确识别文件替换。** 修复 Windows 大数值文件标识比较可能丢失精度的问题，同大小文件被替换后会中止上传，避免把原句柄中的旧文件当成当前选择的文件。

Android 同步停止请求提示、暂停门禁和授权规则，保留手机采集与控制、选定电脑执行的分工。日常 Butler 始终使用单模型，本次未启用真实收款。

完整跨设备停止确认和本机进程退出证据仍在后续可靠性工作范围内；已发出的外部操作不保证撤销。存储对象存在性检查不是内容校验和，也不能恢复历史上已经丢失的文件。

本版由 CI 构建 Windows 安装版与便携版、macOS Intel 与 Apple Silicon、Linux AppImage 与 deb，以及固定证书签名的 Android 预览版。若 APK 未随首批发布，请以发布附件为准，后续通过 Android 补发流程追加。
