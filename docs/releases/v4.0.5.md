# wickrunAI 4.0.5 — 交付验收看产出文件，切回窗口不再空白

交付验收中的原文核对不再只看回答文字。长文档、脚本、字幕和网页现在常常以文件交付，此前要求的原文明明写在产出文件里，验收仍报“答案缺少指定原文”。现在原文核对同时检查回答和本轮产出的文本文件，并说明在哪个文件里找到；比较时忽略大小写、空白、引号样式和 Markdown 标记，措辞、顺序和数字仍须一致。指定文件的原文检查采用同样的比较规则。任务暂停、还没有回答或产出时，这类要求保留为待检查，不再判为未通过。图片、视频等非文本产出不参与原文核对。

修复从其他应用切回时窗口空白、需要按 Ctrl+R 才能恢复的问题。Windows 上被其他窗口覆盖的应用会被系统标记为不可见并停止绘制，切回后可能一直不重绘；现在关闭这项遮挡判断，并在窗口重新获得焦点、显示或还原时主动重绘。界面进程意外退出时自动重新载入，执行中的任务从已保存的进度恢复；若切回时页面已经空白，也会自动重新载入。相关事件写入数据目录下的 logs/window.log，便于再次出现时排查。

界面调整：左上角恢复「对话 / Agent 团队」横向切换，管家入口保留为可折叠项。宽屏下侧栏展开按钮只在侧栏收起时出现，不再同时出现两个；在「群组与共享」中收起侧栏后，左上角同样可以重新展开，关闭按钮加上图标。顶部分享改为分享图标，设置改为齿轮图标。

Android 预览版与 4.0.4 功能相同，由 CI 使用同一把密钥签名，可直接覆盖安装 4.0.3 及以后版本。

验证：类型检查与全部自动回归测试通过；新增产出文件原文核对、宽松比较、暂停时不判定、窗口重绘与崩溃自动重载的测试；在浏览器中核对了宽屏、收起侧栏、群组与共享和窄屏四种布局下的侧栏按钮。Windows 遮挡导致的空白无法在云端复现，需在本机验证。
