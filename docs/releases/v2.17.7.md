# 2.17.7：可选择的多任务建议与文本任务接续

协作空间可把一轮想法梳理带出的建议整理成多个任务。你可以逐项选择、修改目标和完成标准，展开调整先后关系，再一起保存。关闭编辑器后，草稿可从总览继续。

- 总览显示真实保存的任务先后关系。前置任务必须完成并经用户验收，后续任务才能开始；每项仍需单独确认开始。
- 运行前可以查看将传入的已验收文本。运行保存后固定文本和来源，前置任务以后重跑或改名不会替换这次输入。
- 互斥方向、缺失前置、自我依赖、循环和超大方案会在保存或运行前被拒绝。建议不能植入模型、成员、工具或权限。
- 修复提交前快速检查对同一行 `Record` 对象漏算键的误报；正式类型检查仍需通过。

本版先支持文本任务依赖：每轮建议最多 8 项，每项最多 8 个前置，合计前置文本上限 32,000 字符。文件产物接续尚未开放；已有保存的探索流程仍保留原指令，新准备的探索流程使用多任务建议格式。旧的单任务建议仍能导入。

验证范围及限制见 [2.17.7 验收记录](../acceptance/2.17.7/README.md)。本文件随源码交付，不代表已经打包、上传或发布。
