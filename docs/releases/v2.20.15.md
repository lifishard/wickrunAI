# wickrunAI 2.20.15

管家现在能把多模型讨论需求转成可采用的团队和讨论管线，修复“独立复核不能由执行者自己担任”导致方案无法采用的问题。

- **生成真正的讨论安排**：独立准备材料、1–3 轮逐人回应、整理共识与分歧、独立文本复核、用户验收。每轮读取前文，讨论不代替质检。
- **模型分工可调整**：采用前为各角色选择已配置的 API 接入与模型；不把同模型多角色称为多模型讨论。
- **复核实例独立**：执行和复核可以使用同一个职责模板，程序会建立不同成员，避免同一成员复核自己的工作。
- **保留原始材料**：用户提供的需求和提案随任务保存，讨论与复核能读取原文；外部提案中的数字与结论仍是待核实材料。
- **方案可恢复**：格式或分工不合法时自动修正一次；失败回复保留可读正文、原始内容和“修复方案”入口。修复较早方案时锁定对应材料；取消讨论后不因后续补充而重新触发。
- **组队和启动分开**：采用建立团队、工作流和任务草案，任务页检查后再启动。讨论成员可通过提问工具请求用户决定。

生产构建、静态检查和 1026 项回归测试通过；隔离 Electron 客户端验证失败方案恢复、模型调整、真实工作流生成、原文保存和重启恢复。模型执行使用受控测试返回，验证调度和前文传递，不代表真实供应商推理质量。此处为 API 模型讨论；外部 ChatGPT / Claude 客户端本体仍使用会议室接入。
