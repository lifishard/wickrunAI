# wickrunAI Android 4.1.3

本版对齐桌面和网页的 4.1.3 版本。Android 独立源码线保留 4.1.2 已交付的 Butler 当前版本同意、默认关闭例行执行及撤回授权保护，本次没有移植桌面和网页的云文件库上传功能。

Android APK 继续由 CI 构建、签名并核对固定证书，applicationId 和签名不变。日常 Butler 仍然使用单模型，不启用真实收款。

公开安装包：https://github.com/lifishard/wickrunAI-releases/releases/tag/v4.1.3

桌面版本说明：https://github.com/lifishard/wickrunAI/blob/main/docs/releases/v4.1.3.md
