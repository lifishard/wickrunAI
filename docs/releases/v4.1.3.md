# wickrunAI 4.1.3

本次继续修复桌面和网页云文件库上传的可靠性，让断点续传、取消和完成提示对应真实状态。

- **内容改变就创建新的上传身份。** 上传前按固定大小分块读取内容并计算摘要，不再仅凭名称、大小和修改时间复用旧上传。网页不会一次性读入整个大文件；桌面还会检查读取期间的原文件变化，发现变化就停止确认。
- **遇到限流会按要求等待。** 上传重试尊重服务器返回的等待期限，三个并行上传任务共用冷却时间。等待超出本次预算就保留断点，明确提示稍后继续。
- **过期上传链接可以有限续期。** 同一个文件或分片最多续签一次，仍绑定原账户和原上传；持续拒绝会停止，避免无限重试。
- **取消覆盖更多步骤。** 文件检查、上传、签名续期、重试等待和完成请求都接入取消。点击后立即显示正在停止；超过 5 秒未确认则追加等待提示，确认退出后才解除本次上传限制。离开上传组件也会停止本次上传，迟到的响应不会把取消显示成成功。已发出的完成请求可能已被服务器处理，可稍后刷新核对。
- **完成提示更清楚。** 界面分别显示检查文件、上传和等待云端确认；服务器确认后才显示成功。云文件库显示服务器实际单文件上限，并说明存储、预览和模型读取是不同能力。

这里的内容指纹是客户端计算的分块摘要，不代表对象存储已验证标准整文件 SHA。上传旧版断点可能会重新开始，以避免继续复用只有文件元数据的旧身份。

Android 本次同步版本并保留 4.1.2 的授权保护，没有移植桌面和网页的云文件库上传功能。APK 仍由 CI 使用固定签名构建；日常 Butler 保持单模型，不启用真实收款。
