# wickrunAI 3.0.1：登录修复

桌面版 Google 登录现在使用公开的 `https://wickrunai.com` 账户入口，避免旧服务地址的 403 错误。服务端返回结构化错误或非 JSON 错误页面时，桌面版会显示可读的错误信息，不再显示 `[object Object]`。

服务端同时恢复了旧桌面版的登录兼容性，并修复 Android 现有 APK 所用浏览器授权入口；已有 Android APK 无需为本次登录修复重新安装。3.0.1 不包含协作或共享功能。

本地验证：桌面账户回归测试 5/5、完整自动测试 1168/1168、类型检查和生产构建通过。Windows、macOS、Linux 安装包由发布 CI 分别构建；各平台实际安装与登录仍需在相应设备上确认。
