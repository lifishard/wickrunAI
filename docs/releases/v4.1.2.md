# wickrunAI 4.1.2

本次先修复编辑恢复、文件上传重试和停止任务的可靠性。Windows、macOS、Linux 与 Android 使用同一版本号；各平台实际改动如下。

- **桌面未保存编辑可在重启后恢复。** 文本、Word、表格和 PDF 编辑草稿写入本机记录。只有本机写入确认后才显示已保留；文件本身仍需点击保存。重新打开时保留原文件指纹，外部修改不会被旧草稿直接覆盖。输入到草稿确认之间仍存在短暂窗口，关闭前请等待确认。
- **关闭本机中继会请求停止当前任务。** 桌面执行端使用现有客户端取消接口，运行期间检查云端取消状态，避免停止后的迟到输出再次提交。云端取消尚未确认时保留恢复记录；远端停止依赖执行端联网，离线不能即时生效。
- **云文件上传完成重试可以恢复。** 对象已写入但数据库更新失败时，重试会核对已有对象并完成登记。上传会话拒绝复用为另一份声明不同的文件，并检查分片编号和长度。声明的 SHA 用于身份匹配，当前对象存储接口并未提供完整内容 SHA 验证。
- **Android 补齐 Butler 当前数据范围同意。** 旧设置不能直接沿用为新的授权，例行主动执行默认关闭；界面运行时及原生采集入口均检查当前同意。撤回后停止继续采集和管家工作。

日常 Butler 继续使用单模型；本次不开放自动双模型协作、不启用真实收款。Android 仍保留其独立源码线，不能据同版本号推断桌面全部功能已经移植。
