## 本轮实现与修复

任务页可选择文本/文件，选择工作目录以及只读/修改能力；运行命令单独展开启用。可直接完成或独立复核，保留角色模型与职责定制。读取使用副本；修改与命令逐项批准，即使项目设为全部批准也不放宽。只读分析复核使用文本快照，修改复核读取版本化文件产物。差异合并仍需用户明确操作。

任务、成员来源和运行均记录文件范围。运行器和主进程检查目录、能力与来源，选择第二根目录不会回落到第一根；新文件成员/流程不能用于无范围或不同范围的任务。页面同时过滤不匹配选项。旧无标记成员及运行保持兼容。模型/职责复制与团队方案保存不带入目录、工具或技能授权。复核固定只读，修正 list_dir 工具名称；只读执行不发布空文件产物。

实际应用测试发现 Windows 进度文件原子替换间歇返回 EPERM，现仅对 Windows EPERM/EBUSY/EACCES 进行有限重试。备份与主文件共享 10/20/40/80/100 ms 的 250 ms 总预算；重试前及最终替换前重新比较主文件哈希。外部修改、磁盘满和持续失败仍停止；不删除目标文件作为降级替代。暂停回调不再掩盖原始保存错误。

只读实测还发现完成检查把系统协议说明当成任务要求。新文件运行单独提供实际目标/验收和用户补充；复核传入只读职责。否定按子句处理，既识别“不得修改”，也不会把“修改 README；不得修改其他文件”整体视为无修改要求。读取仍需成功工具证据，实际修改/测试仍保留对应证据闸门。此为有界文本规则，不是完整语义证明。
