## 已实现范围

U0c-b 的文本任务接续：一轮探索可建议 1–8 项任务，用户逐项编辑、选择及调整前置关系后原子保存。建议采用白名单，只保留任务文本、同组依赖、互斥分组与来源；模型不能指定执行工具、权限、成员或接入。旧单任务格式兼容；无效建议保留原文，仍可手工创建任务。关闭后草稿保留，总览可继续编辑。

持久任务关系与建议来源分别展示。前置任务必须有最新创建且已明确验收的完整文本运行；失败、取消、未核实、未清空审批或预算预留、探索建议、文件产物均不满足条件。保存运行时固定源任务、源运行、节点、尝试及原文；运行器开始、主进程新运行写入与领取分别复核。旧无依赖运行保持兼容。

每任务最多 8 个直接前置；总文本（含标题、目标、验收与产出）最多 32,000 字符，超限拒绝，不静默截断。已有运行的任务不能改写依赖；前置任务后来重命名、修改目标或新增运行，不替换已保存的输入。新建后续运行仍检查当时最新前置运行及任务要求。

## 实际桌面操作

使用现有 Playwright Electron 接口启动仓库的实际 Electron 主进程和最终生产页面。独立 userData 与本机合成 HTTP 服务；启动前仅种入一项已完成探索记录，之后所有编辑、保存、启动与验收都通过产品界面，未通过隐藏状态接口推进运行。未操作日常安装版、OpenAI 窗口或真实服务商。

| 操作与证据 | 结果 |
|---|---|
| 去掉已选任务的前置项 | 保存禁用，解释需同时选择前置任务 |
| 修改目标、关闭、刷新、从总览继续 | 修改保留，可继续保存 |
| 明确放弃草稿后刷新 | 总览继续入口消失，原始建议和任务不变，可重新打开建议 |
| 保存两项建议 | 共 3 任务、1 个原始探索运行，HTTP 请求 0 |
| 先尝试后续任务 | 运行前检查禁用开始，说明前置尚未运行，运行/请求数不增加 |
| 从前置任务确认开始并验收 | 实际 HTTP 1 次，结束节点经界面批准才完成 |
| 后续任务的运行前检查 | 可展开看到前置的实际文本，开始按钮启用 |
| 确认后续开始并验收 | 第二个真实本机请求包含前置标记，持久运行保存相同原文与源运行身份 |
| 刷新与窄窗口 | 任务及关系保留；720 px 时关系区左右在窗口内，无自身横向溢出 |
| 独立进程重新启动 | 使用相同独立目录，已完成运行、关系与冻结文本保留，不新增模型请求 |

两个合成请求共报告 600 tokens；这只是夹具用量，不是供应商实报费用。初始探索结果由夹具提供，未证明真实模型会稳定输出有效多任务建议。
