# U0b：真实规划与首次使用验收记录

当前状态：**尚未执行本轮真实模型试验，也没有首次使用者样本**。2.17.5 已安装，版本元信息已核对。原生桌面控制在重新选择窗口后仍返回 `foreground window did not report a process id`；本轮转用隔离 Electron 的合成数据验证总览，不能据此填写下表的真实结果。

## 试验约束

使用单独的合成测试项目，不引用日常对话、文件或个人信息。允许的入口只有 SenseNova、omni `auto/` 和 OpenRouter 免费路由。确认接入与模型后再启动，关闭自动接力。记录实际派发身份；网关内部选择不等于用户直接选择付费路由。缺失用量写“未知”，不写零费用。

保持应用默认 429 自动退避及 Retry-After 规则。记录首次请求、重试倒计时和最终状态；若触及试验时长或预算就通过应用暂停，保留失败和重试证据。一次入口失败不推断整个平台不可用。

## 固定情境

| 情境 | 合成输入及后续操作 | 检查重点 | 本轮结果 |
|---|---|---|---|
| 模糊想法 | “我想让邻居们多认识一点，但还没想好做什么。” | 无需先命名、选流程或写完成标准；产出至少两个方向及取舍 | 未执行 |
| 信息不足 | “想做一个让人愿意坚持的小项目，时间和预算还没决定。” | 已知与假设分开；最多三个有助于下一步的澄清问题；不擅自规定场地、日期或支出 | 未执行 |
| 改变主意 | 在前一轮补充：“我改主意了，不做线下活动，预算为零，改成线上读书交流。” | 新建议遵守最新补充，不继续沿用已否定的线下方案；上一轮不占住后续运行名额 | 未执行 |
| 无效建议 | 对不符合预期的实际建议补充：“这个方向不合适，先别建立任务，帮我换两个方向。”；若自然出现格式错误，另记样本 | 不合适的建议可拒绝和重谈；无法解析时保留原文并手填；无效结果不能自动派发 | 未执行 |

格式损坏无法要求真实模型稳定复现。解析器的损坏、截断和歧义回归属于受控工程证据；若没有真实无效格式样本，应保留“未观察到”，不能用模拟结果填充真实样本。

## 每次记录

- 应用版本、时间、情境、用户选择的免费入口与模型、实际派发路由（脱敏）。
- 用户从原始想法到可编辑下一任务的问答轮数；每轮问题数；错误假设及是否修正。
- 保存建议前后任务数、运行数与请求数；明确保存不执行，运行须另行确认。
- 成功、失败、退避、主动暂停分别记录；已知 tokens、失败请求用量缺口和证据位置。
- 使用者能否说明：下一步是什么、谁来做、怎样结束、保存建议是否已开始执行。

## 首次使用者试验

参与者应此前未使用本协作空间，也不熟悉节点编排。先只给情境，不教操作路径；记录耗时、求助次数、误点次数、是否独立完成以及对上述四个问题的回答。至少一个真实首次使用样本是进入评估的最低条件，不足以证明普遍可用性或显著降低学习成本。若无旧入口对照，只报告观察，不报告改善比例。

验收出口：四类真实规划情境有记录；无越权执行；用户能通过补充修正方向；至少一位首次使用者独立走到可执行的下一任务并正确解释关键步骤。未达到时继续保留 U0b 待验收，不阻塞可以独立验证的工程施工。
