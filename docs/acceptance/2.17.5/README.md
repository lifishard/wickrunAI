# 2.17.5 想法起步与真实流程预览验收

日期：2026-09-20。基线 7c58d7f / 2.17.4；只读核实已安装 app.asar 的版本为 2.17.4，用户确认已发布。本轮源码 2.17.5 未提交、打包、安装或发布。

## 实际操作

主负责人通过 Windows 原生界面控制操作独立 Electron 实例，连接 127.0.0.1:9351 合成 HTTP 服务。未操作 OpenAI/ChatGPT 窗口；仅重启本轮自建的 2.17.5 测试实例，日常安装应用保持打开。测试数据与真实用户数据隔离。

1. 在“协作空间 → 说说你的想法”输入“我想办一场社区活动，但还没想好做什么。”。没有填写任务名、验收条件或设计 workflow，保存成功。
2. 重启专用实例加载完整修改，原始想法保留；选择已配置的本机模型，准备两位助手和固定流程。此前夹具有两位示例成员与一个复核流程；准备后共四位成员、两个流程，运行数与 HTTP 请求数仍为零，见 [prepared.json](prepared.json)。
3. 点击确认后，实际运行器先派方向探索，再把结果交给方案整理；返回可读方向、问题及可修改任务建议，共两次 HTTP 请求、夹具报告 600 tokens。
4. 首次“继续梳理”实测暴露默认单并发名额被上一轮待验收占用的问题。保留该未派发运行，修复后通过界面停止它，记录为 cancelled、零 attempts、零 tokens；它不算成功运行。
5. 新增运行器/存储回归复现原失败后验证修复。重新从第一轮结果补充“预算200元，面向邻居。请继续比较野餐与室内备选方案。”，界面结束原规划轮，再确认新的轮次；接续成功，两个模型步骤收到补充，返回包含预算和对象的建议。
6. 点击“修改建议，建立下一项任务”，本轮规划结束。把建议目标改为“比较预算200元、面向邻居的社区野餐和室内备选方案；先写方案，不联系任何人。”并保存。独立执行任务保留来源，未创建执行运行，HTTP 总请求数仍为四。
7. 选择已有“写作与独立检查”，看到 v1、草稿另有修改提示及真实返工连接。点击“独立检查”，读到检查助手、输入要求和通过/返工/无法核实三个去向。预览未把草稿里“草稿尚未发布的检查”当作运行节点。
8. 最终构建重载后，修改后的目标、来源链接、已有流程选择及版本差异提示仍在；预览使用普通用语并显示助手名称。窗口从普通到最大化均无页面级横向溢出，较长内容可滚动查看。
